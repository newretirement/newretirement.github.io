Codex

Connect the Boldin MCP server to Codex.

Step 1 — Add the server​

Copy and paste this exact line into your Terminal and press Enter:

codex mcp add boldin --url https://www.boldin.com/mcp

This registers boldin as a streamable HTTP MCP server in ~/.codex/config.toml.

Step 2 — Confirm it’s there​

codex mcp list

You should see boldin in the list.

Step 3 — Start Codex and connect​

  1. Type codex to start.
  2. Inside Codex, type /mcp to confirm boldin is connected and its tools are listed.

Codex automatically detects that the Boldin server uses OAuth and prompts you to sign in when needed — follow the prompt (this usually opens a browser), log in with a Boldin account, and approve access.

Optional: you can sign in ahead of time instead with codex mcp login boldin.

Using it​

Just ask Codex normally — e.g. “What can the Boldin tools do?” Codex uses the server automatically when helpful.
