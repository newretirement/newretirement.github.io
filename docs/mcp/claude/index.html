Claude

Connect Boldin to Claude — the web, desktop, and mobile apps — without any setup in a terminal.

Boldin is listed in the Claude directory, so you can add it in a couple of clicks.

Step 1 — Open the Boldin listing​

Go to the Boldin listing in the Claude directory:

claude.ai/directory/boldin

Sign in to Claude if prompted. You’ll see the Boldin listing with a description of what it can do and the list of tools it provides.

Step 2 — Connect to Claude​

Click Connect to Claude. Claude will send you to Boldin to sign in — log in with your Boldin account and approve access.

Once you’re back in Claude, Boldin appears under Settings → Connectors as connected.

Note: Boldin is a community connector. Claude shows a notice that community connectors are reviewed automatically but not verified by Anthropic — this is expected, and the connector is built and maintained by Boldin.

Step 3 — Use it in a chat​

  1. Start a new chat.
  2. Open the tools menu (the + button next to the message box) and make sure Boldin is turned on.
  3. Ask Claude normally — e.g. “What can the Boldin tools do?” or “How would retiring two years earlier affect my plan?” Claude uses Boldin automatically when helpful.

Prefer the terminal?​

If you use Claude Code instead of the Claude apps, see Claude Code.
