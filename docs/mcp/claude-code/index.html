Claude Code

Connect the Boldin MCP server to Claude Code.

Step 1 — Add the server​

Copy and paste this exact line into your Terminal and press Enter:

claude mcp add --transport http boldin https://www.boldin.com/mcp

You should see Added HTTP MCP server boldin.

Step 2 — Confirm it’s there​

claude mcp list

You should see boldin in the list.

Step 3 — Start Claude and connect​

  1. Type claude to start.
  2. Inside Claude, type /mcp.
  3. It will ask you to sign in — follow the prompt (this usually opens a browser). Log in with a Boldin account and approve access. Once it says connected, you’re done.

Using it​

Just ask Claude normally — e.g. “What can the Boldin tools do?” Claude uses the server automatically when helpful.
