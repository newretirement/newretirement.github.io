MCP Server

The Boldin MCP (Model Context Protocol) server lets AI coding assistants like Claude Code and Codex connect to Boldin tools directly, so you can ask them to work with Boldin from your normal workflow.

The server is available at:

https://www.boldin.com/mcp

It uses HTTP transport and requires you to sign in with a Boldin account.

Set up​

  • Claude Code — connect the Boldin MCP server to Claude Code.
  • Codex — connect the Boldin MCP server to Codex.
