ChatGPT

Connect Boldin to ChatGPT without any setup in a terminal.

Boldin is available as a ChatGPT plugin, so you can add it in a couple of clicks.

Step 1 — Open the Boldin plugin​

Go to the Boldin plugin page in ChatGPT:

Boldin for ChatGPT

Sign in to ChatGPT if prompted.

Step 2 — Connect and sign in​

Click Connect. ChatGPT will send you to Boldin to sign in — log in with your Boldin account and approve access.

Step 3 — Use it in a chat​

Start a new chat and ask ChatGPT normally — e.g. “What can the Boldin tools do?” or “How would retiring two years earlier affect my plan?” ChatGPT uses Boldin automatically when helpful.

Prefer the terminal?​

If you use Codex instead of the ChatGPT app, see Codex.
