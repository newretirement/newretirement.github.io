Nationwide

This document describes how to create and use JSON Web Tokens (JWT) for authenticating requests to the Nationwide API endpoints.

Overview​

The Nationwide API uses JWT-based authentication for secure, stateless authentication. Clients must generate a properly signed JWT and include it with each API request.

For more information about JWTs and to debug/test your tokens, visit jwt.io.

JWT Requirements​

Required Claims​

Your JWT payload must include the following claims:

ClaimTypeDescriptionExample
audstringAudience - must include “boldin.com”"boldin.com"
externalIdstringExternal user identifier used to lookup the user in the system"12345"
nbfintegerNot Before - Unix timestamp, must be in the past1699564800
expintegerExpiration - Unix timestamp, must be in the future1699651200

Algorithm and Signing​

The JWT must be signed using the HS512 HMAC algorithm with the shared secret key provided by Boldin.

Ruby Example:

require 'json/jwt'

payload = {
  "aud" => "boldin.com",
  "externalId" => "12345",
  "nbf" => Time.now.to_i,
  "exp" => (Time.now + 1.hour).to_i
}

jwt = JSON::JWT.new(payload)
token = jwt.sign(your_secret_key, :HS512).to_s

Python Example:

import jwt
import time

payload = {
    "aud": "boldin.com",
    "externalId": "12345",
    "nbf": int(time.time()),
    "exp": int(time.time()) + 3600  # 1 hour from now
}

token = jwt.encode(payload, your_secret_key, algorithm="HS512")

Node.js Example:

const jwt = require('jsonwebtoken');

const payload = {
  aud: 'boldin.com',
  externalId: '12345',
  nbf: Math.floor(Date.now() / 1000),
  exp: Math.floor(Date.now() / 1000) + 3600  // 1 hour from now
};

const token = jwt.sign(payload, your_secret_key, { algorithm: 'HS512' });
