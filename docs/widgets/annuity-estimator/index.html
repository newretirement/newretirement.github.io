Annuity Estimator

The Annuity Estimator widget lets you explore the different options for annuities.

Embed code
<script
  type="module"
  src="https://widgets.boldin.com/annuity-estimator/index.js"
/>
<boldin-annuity-estimator
  variant="widget"
  apiKey="YOUR-API-KEY"
></boldin-annuity-estimator>

Configuration options​

Attribute nameDescriptionTypeDefault value
apiKeyRequired. Your Widget API key (one assigned to you).string—
variantOptional. Layout option (widget or full) as illustrated below.stringwidget
fullACUrlOptional. The location of the widget’s full variant if one is defined. It defaults to the current page.string.
signupUrlOptional. The destination linked to the full variant’s CTA (Call to Action) button. Note: if you’re a Boldin affiliate, see the Deployment considerations section below.stringhttps://www.boldin.com/retirement/planner-signup/
envOptional. Useful only for testing pre-release versions of the API. Set to staging to send requests to the pre-release version; otherwise, requests will go to the production API.stringnull

Deployment considerations​

We’ve designed the Annuity Estimator widget variants for different deployment scenarios. The smaller widget variant can be placed alongside a blog article or other content on your site, whereas the larger full variant is better suited to its own dedicated page.

What’s more, the two variants can work together when desired. Consider the interaction flow in the diagram above: a visitor comes to an article on your site and begins interacting with the widget variant. Intrigued, the visitor clicks the call to action (CTA) on the widget variant (configured using the fullACUrl attribute) and navigates to the widget’s full variant, whose form fields will reflect any changes made to the input data. The full variant’s call to action (configured using the signupUrl attribute) can then take the visitor to a separate destination — by default, the Boldin signup page, but configurable to any URL you choose.

info

Of course, you don’t need to use both variants if you don’t want to; the full variant works just fine on its own.

tip

If you’re a Boldin affiliate, you’ll want to make sure that any visitors you send to Boldin have the proper attribution — which means adding your attribution credentials to the signupUrl attribute. Here’s an example of the widget embed code with (fictional) attribution credentials:

<boldin-annuity-estimator
  apiKey="YOUR-API-KEY"
  variant="full"
  signupUrl="https://www.boldin.com/retirement/planner-signup/?nr_product=NRC&nr_a=00&nr_medium=affiliate&utm_source=000&utm_medium=affiliate"
></boldin-annuity-estimator>
