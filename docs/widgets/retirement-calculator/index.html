Retirement Calculator

The Retirement Calculator widget is a simple widget that allows you to forecast your retirement savings.

This is on the Boldin website at https://www.boldin.com/retirement/simple-retirement-calculator/

Embed code
<script
  type="module"
  src="https://widgets.boldin.com/retirement-calculator/index.js"
/>
<boldin-retirement-calculator
  apiKey="YOUR-API-KEY"
  variant="widget"
  signupUrl="https://www.boldin.com/retirement/planner-signup/"
/>

Configuration options​

Attribute nameDescriptionTypeDefault value
apiKeyRequired. Your Widget API key (one assigned to you).string—
variantOptional. Layout option (widget or full) as illustrated below.stringwidget
openNewTabOptional. Controls whether the CTA (Call to Action) button opens the signupUrl in a new tab or the current tabbooleanfalse
signupUrlOptional. The destination linked to by the CTA (Call to Action) button.stringhttps://www.boldin.com/retirement/planner-signup/
envOptional. Useful only for testing pre-release versions of the API. Set to staging to send requests to the pre-release; otherwise, requests will go to the production API.stringhttps://api.boldin.com

tip

If you’re a Boldin affiliate, you’ll want to make sure that any visitors you send to Boldin have the proper attribution — which means adding your attribution credentials to the signupUrl attribute. Here’s an example of the widget embed code with (fictional) attribution credentials:

<boldin-retirement-calculator
  apiKey="YOUR-API-KEY"
  variant="full"
  signupUrl="https://www.boldin.com/retirement/planner-signup/?nr_product=NRC&nr_a=00&nr_medium=affiliate&utm_source=000&utm_medium=affiliate"
></boldin-retirement-calculator>
