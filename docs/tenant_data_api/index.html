Tenant Data API

Overview

Boldin Tenant Data API provides a set of endpoints for securely storing, retrieving, and managing user data. This API is designed to help tenants maintain data integrity in a scalable and efficient manner.

The API is built on RESTful principles, making it easy to integrate with existing systems and applications. It supports standard HTTP methods such as GET, POST, PUT, and DELETE for performing CRUD (Create, Read, Update, Delete) operations on data resources.

Getting Started

To get started with the Boldin Tenant API, you will need a tenant admin account, with API access enabled. You can then generate an API key from your admin dashboard, under the “API Clients” section.

Once you have your API key, explore the complete API documentation.
